# Tayyib Online SHOP — MERN Stack (শেখা/এক্সপেরিমেন্টাল ভার্সন)

এটা আপনার লাইভ PHP সাইটের **পাশাপাশি** আলাদা একটা প্রজেক্ট — PHP সাইটে কোনো প্রভাব ফেলে না।

**যা আছে:** প্রোডাক্ট ক্যাটালগ (ভ্যারিয়েন্ট সহ) → কার্ট → চেকআউট → অর্ডার (স্টক অটো কমে) → অর্ডার ট্র্যাকিং

## আগে যা ইনস্টল করতে হবে (Windows)

1. **Node.js (LTS)** — nodejs.org থেকে নামিয়ে ইনস্টল করুন
2. **MongoDB** — দুটো উপায়ের যেকোনো একটা:
   - **সহজ (রিকমেন্ডেড):** mongodb.com/atlas এ ফ্রি অ্যাকাউন্ট খুলে একটা ফ্রি ক্লাস্টার বানান, সেখান থেকে Connection String নিন
   - **লোকাল:** MongoDB Community Server ইনস্টল করুন

## চালানোর ধাপ

### ১) ব্যাকএন্ড
```
cd backend
copy .env.example .env
```
`.env` ফাইল খুলে `MONGO_URI` এ আপনার MongoDB-র ঠিকানা বসান, আর `JWT_SECRET` এ যেকোনো লম্বা এলোমেলো লেখা বসান (যেমন ৩০-৪০ অক্ষরের র‍্যান্ডম স্ট্রিং), তারপর:
```
npm install
npm run seed         (একবারই — ডেমো প্রোডাক্ট ঢুকবে)
npm run seed:admin   (একবারই — অ্যাডমিন ইউজার তৈরি হবে: ইউজারনেম admin, পাসওয়ার্ড tayyib2026)
npm run dev          (সার্ভার চালু থাকবে, এই উইন্ডো খোলা রাখুন)
```
ব্রাউজারে http://localhost:5000 খুললে "ব্যাকএন্ড চালু আছে ✅" দেখা যাবে।

### ২) ফ্রন্টএন্ড (নতুন টার্মিনাল উইন্ডোতে)
```
cd frontend
npm install
npm run dev
```
তারপর ব্রাউজারে http://localhost:5173 খুলুন।

## ফোল্ডার কাঠামো (শেখার জন্য)

- `backend/models` — ডাটাবেজের গঠন (Product, Order) — MySQL-এর টেবিলের সমতুল্য
- `backend/routes` — API endpoint (products, orders) — PHP-র আলাদা আলাদা ফাইলের সমতুল্য
- `frontend/src/pages` — পেজগুলো (Shop, Checkout, Track)
- `frontend/src/context/CartContext.jsx` — কার্টের ডেটা সব পেজে শেয়ার করার জায়গা (PHP-তে $_SESSION যেটা করত)

## অ্যাডমিন প্যানেল

ব্রাউজারে http://localhost:5173/admin/login এ গিয়ে লগইন করুন (ইউজারনেম `admin`, পাসওয়ার্ড `tayyib2026` — `npm run seed:admin` থেকে)। লগইন করলে সব অর্ডার দেখা যাবে এবং স্ট্যাটাস বদলানো যাবে।

এটা কীভাবে কাজ করে (শেখার জন্য):
- লগইন করলে ব্যাকএন্ড একটা **JWT টোকেন** ফেরত দেয়, যেটা ব্রাউজারের `localStorage`-এ সেভ থাকে
- এরপর প্রতিটা অ্যাডমিন API কলে (`/api/orders` ইত্যাদি) এই টোকেনটা `Authorization: Bearer <token>` হেডারে পাঠানো হয়
- ব্যাকএন্ডের `middleware/auth.js` প্রতিটা প্রোটেক্টেড route-এর আগে এই টোকেন যাচাই করে — না থাকলে বা ভুল হলে 401 এরর দেয়
- এটা PHP-র `session_start()` + `$_SESSION['admin_logged']`-এর মতোই কাজ, পার্থক্য হলো MERN-এ session সার্ভারে সেভ থাকে না (stateless), পুরো তথ্য টোকেনের ভেতরেই এনকোড করা থাকে

## নিরাপত্তা নোট

- অর্ডারের দাম সার্ভারে ডাটাবেজ থেকে হিসাব হয়, ক্লায়েন্ট থেকে আসা দাম বিশ্বাস করা হয় না
- অর্ডার তালিকা ও স্ট্যাটাস বদলানো এখন শুধু লগইন করা অ্যাডমিনের জন্য (JWT দিয়ে সুরক্ষিত)
- লাইভ ব্যবহারের আগে `JWT_SECRET` অবশ্যই শক্তিশালী ও গোপন রাখতে হবে, আর ডিফল্ট অ্যাডমিন পাসওয়ার্ড বদলে নিতে হবে
